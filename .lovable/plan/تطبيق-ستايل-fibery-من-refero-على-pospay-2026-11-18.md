# تطبيق ستايل Fibery (من Refero) على PosPay

المرجع: شاشة Fibery "Interview Calendar" — خلفيات بيضاء، نص رمادي داكن، خطوط فاصلة رفيعة، تخطيط 3 أعمدة (قائمة جانبية / محتوى / لوحة تفاصيل)، ألوان حالة هادئة.

## اللي هيتغير
1. **الألوان (tokens) في `src/styles.css`** — نستبدل الألوان الحالية بألوان المرجع بصيغة oklch:
   - النص الأساسي `#242729`، الرمادي الثانوي `#98A0A5`
   - الأخضر `#26A680` = primary (تأكيد الحضور)
   - الوردي `#D24175` = destructive/تنبيه (تأخير، استثناء)
   - الأخضر الرمادي `#577E7D` = accent
   - خلفية بيضاء، borders رمادي فاتح جدًا، radius أصغر (6px)
   - توكنز جديدة للحالات: `--success`, `--warning-soft` للـ tags الملونة
2. **الخط**: نفضل `IBM Plex Sans Arabic` للعربي (الـ San Francisco مش بيدعم العربي كويس)، مع system-ui للإنجليزي.
3. **هيكل التطبيق**: layout ثلاثي في `__root.tsx` — sidebar على البداية (start) بروابط بأيقونات وأقسام، ومحتوى في النص. اللوحة الجانبية للتفاصيل تستخدم في الشاشات اللي تحتاجها لاحقًا.
4. **الشاشات الحالية** (`/`، `/sign-in`، `/reception/qr`، `/attend`، `/phone`، `/attendance-questions`) تتظبط على الستايل الجديد من غير تغيير أي منطق.

## اللي مش هيتغير
- أي business logic أو server functions أو قاعدة بيانات.
- RTL والـ logical CSS و i18n `t()` — كل نص جديد في `ar.json`/`en.json`.
