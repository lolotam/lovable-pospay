# رحلات المستخدم للاختبار اليدوي

هذا المجلد فيه ملف لكل PR يغيّر شيء يقدر المستخدم يشوفه أو يجرّبه على الموقع الحقيقي
(https://app2.pospay.systems). الهدف إن وليد يقدر يختبر كل تغيير بنفسه بعد الدمج.

## طريقة الاستخدام

1. افتح ملف الـ PR اللي تبي تختبره.
2. نفّذ الخطوات بالترتيب، وقارن النتيجة بالعمود "المفروض يصير".
3. علّم على المربع `[x]` لما تنجح الخطوة. لو فشلت، اكتب اللي صار تحت "ملاحظات الاختبار" في نفس الملف.

## القاعدة لكل PR جديد

كل PR يغيّر سلوك يشوفه المستخدم يضيف ملف هنا باسم `<رقم PR>-<اسم مختصر>.md`، ويكون فيه:

- رابط الـ PR والـ commit اللي اندمج.
- الشروط قبل البدء (حساب بأي دور، إعداد مطلوب، migration لازم تكون مطبقة).
- الخطوات مع النتيجة المتوقعة، ومعها حالات الخطأ المهمة.
- اللي ما يقدر المستخدم يختبره من الواجهة (لو فيه)، وليش.

PR بدون أي شيء ظاهر للمستخدم (مثل محرك حسابات بدون شاشة) يضيف ملف قصير يقول هالشي بوضوح.
